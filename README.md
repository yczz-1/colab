# A股主板周频多因子：Colab研究与手动调仓

本金默认20,000元，免费数据，目标是稳健多因子研究。**这是第一版研究工具，不是已经验证盈利或可以直接实盘的策略。**

## Colab连接超时时：Mac下载、Colab离线导入

本机是Mac可使用 [LOCAL_DATA.md](LOCAL_DATA.md)：下载最新版代码包，解压后在终端进入ashare_weekly目录，运行 `bash mac_download.sh`。先验证30只真实股票的下载；完成后在最新版Notebook设 `MODE='bundle'`，上传生成的 `market_sample_*.zip`。本机连接能否成功仍需验证，离线导入不会改善原数据源的历史偏差。

## 在 Colab 上运行

1. 把 `A股周频多因子.ipynb` 上传至 Google Colab。
2. 运行第一格代码，按提示上传交付包 `ashare_colab.zip`。后续代码会进入 `/content/ashare_weekly`。
3. 首先保持 `MODE='demo'`，从上到下运行。模拟数据只验证软件，不代表A股收益。
4. 改为 `MODE='free'` 连接 BaoStock。先保持 `MAX_SYMBOLS=30` 验证接口；这30只股票按代码排序，存在严重样本偏差，不能用于选策略。
5. 将 `MAX_SYMBOLS=None` 获取服务商能返回的全部主板股票。全市场多年行情和财报下载可能需要较长时间，按股票缓存，中断后可重跑。建议使用Google Drive缓存；不要公开含持仓的Drive文件。
6. 缺数据、接口错误、缺质量因子时直接报错，不自动切换到模拟数据或静默删掉因子。

本地运行：`python -m pip install -r requirements.txt`，`python -m unittest discover -s tests -v`，`python run_demo.py`。

## 策略定义 v0.1（待验证的假设）

- 股票池：沪深主板普通股票；代码前缀600/601/603/605及000/001/002/003。包含原中小板，不含创业板、科创板、北交所。
- 排除：信号日ST、上市不满365个自然日、信号日停牌、近20个观测日平均成交额不足2000万元、缺因子数据；不依据今天的ST标签追溯过滤历史。
- 价值：正PE TTM与正PB MRQ的倒数，分别在当期截面2.5%/97.5%缩尾、标准化，再等权合成。
- 质量：最近可用年度报告的ROE；只用年度报告，避免把不同季度的累计ROE放在一起比较。报告公告日严格早于信号日；公告距信号不超过400天，财年末距信号不超过550天。ROE必须为正。暂不采用自由现金流、应计利润等依赖额外历史披露数据的因子。
- 动量：前20个观测日的复权收盘价 / 前120个观测日的复权收盘价 - 1，即约六个月剔除最近一个月。
- 综合分数：价值35%、质量35%、动量30%；权重为研究起点，没有经过参数寻优。
- 选排名前8只，按过去60个观测日波动率倒数分配，单股目标权重最多20%。截断后的余额保留现金，不重新分配。
- 保留2%目标现金。可选趋势过滤：沪深300低于此前120个交易日均线时，目标股票总敞口减半。趋势过滤可能在震荡市损耗收益，不保证回撤上限。
- 周频：以行情日历相邻周之间的转换为依据，上周最后交易日收盘产生信号，下周第一个交易日开盘研究成交。遇节假日不是机械地每5条数据调仓。
- 不使用固定止损作为第一版默认项；先评估分散、现金比例、趋势过滤和换手成本。

没有行业中性化、行业集中度约束、债务/现金流质量约束或个股缓冲换仓规则，需在数据完善及基线评估后迭代。价值与ROE容易集中在金融等行业，因此行业集中度是进入模拟盘前必须补充的审查。

## 回测的边界（请先读）

`ashare/research.py` 是**复权总收益研究回测**：持有的是连续可分割的研究单位，现金分红通过复权价格假设再投资。它不是逐股现金账户的真实成交回测：

- 不模拟100股整数手、分红税、配股缴款、退市结算、盘中排队及真实成交价。
- 估算单笔佣金和最低5元收费、滑点、历史印花税以及过户费。佣金默认万三，实际应以券商账单确认；其他经手费是否含在佣金内也应确认。
- 卖出印花税2023-08-28起万五、此前千一；过户费2022-04-29起十万分之一，此前十万分之二，按双边估算。若延伸至更早制度区间，需要扩展费率表。
- 买卖按原始开盘价检查停牌和普通主板10%/ST5%涨跌停，触及开盘限制保守不成交。未建模特殊交易状态或逐日监管规则变更。
- 使用信号时已知的近20日成交额限制单笔名义金额，不用成交日完整日成交量作为开盘可用信息。没有真实竞价深度或冲击模型。
- 已持仓股票缺失当日估值时中止，不把它当作零收益或按不存在处理。停牌有服务商报价时允许估值但禁止交易。
- 只有周初尝试执行，未成交部分不逐日追单。

**不能把此回测收益写成“2万元按整数手实际可获得的收益”。** 进入实盘前还需逐笔原始价格回测，纳入经核验的分红送转/配股、交易日历、交易状态及整数手账户，并与模拟交易核对。

免费数据限制：BaoStock证券主表尽量保留退市股票，但其历史完整性未独立审计；历史财报虽有公告日，可能是事后修订值，不是可验证的逐版本历史快照。历史ST、PE/PB口径及复权也需抽样核验。报告总会标记 `financial_vintages_verified=false` 和 `historical_universe_audited=false`，不能据此声称无未来数据偏差或无幸存者偏差。

当前云环境没有BaoStock服务TCP端口的网络授权，因此未在此下载真实行情。其客户端包已安装并检查API；真实连接和返回字段需要在Colab验证。不会绕过网络限制，也不会声称下载已通过。

## 实验记录与验证

先固定三组基线：动量、价值+质量、综合多因子；都按同一股票池准入条件、时间区间和成本假设比较，并额外比较趋势过滤开关。质量或估值缺失会导致各基线的有效样本不同；比较时要检查覆盖率，不能把差异全归因于因子。

默认开发期2019–2021年、验证期2022–2023年；2024–2025年留出，Notebook默认不运行留出期。仅首次使用工具者可把它作为未观察区间；如果你已看过或反复使用这些年份，应另外选取未查看的后续区间或采用前向模拟。反复查看验证期同样会过拟合。

每次运行保存参数、配置哈希、数据哈希、数据范围和来源、净值、研究交易、未成交记录、年度收益。目录不允许覆盖。数据摘要包含股票数及是否抽样；保留所有实验，不只保留最好的一次。年化收益、最大回撤、零无风险利率夏普、沪深300价格指数收益均为研究指标。沪深300价格指数不含分红，与复权股票收益口径不完全一致。

后续必须做：滚动样本外检验、跨年度稳定性、1.5–2倍成本压力测试、5/8/10只持仓比较、去掉任一因子的敏感性检查。当前没有实现完整的这些研究，不应把3个基线比较视为最终策略筛选。

## 手动调仓清单

`ashare/orders.py` 独立于研究回测，以券商**实际持仓**为准：

- 输入 `holdings.csv`：`code,shares,sellable`，股数和可卖数量必须是非负整数；可卖数量由券商提供，不能用总持仓推断T+1。
- 输入 `quotes.csv`：`code,price,upper,lower,tradable`；报价及当日涨跌停价格需用券商/交易所最新数据核实，`tradable`为0/1。所有持仓和目标股票都要有报价。
- 显式输入账户可用现金。Notebook不会根据研究净值假造实际持仓或现金。
- 买入按100股单位、费用和当前现金计算。未成交的预计卖出收入不用于买单融资；卖单成交后更新现金与持仓再生成。
- 参考限价包含默认0.1%的价格缓冲，触及当日涨跌停则不给交易数量；不是保证成交的价格。
- 清单仅供人工审核，不下单；在模拟/真实账户开盘成交前，更新报价、现金、可卖数量，核对ST、停牌、公告、行业集中度和券商费用。

当候选股价格偏高时，2万元可能买不够8只；工具保留现金，不自动追买更低排名的股票。这一现象需要在真实整数手回测中评估。

## 进入实盘前

先完成全市场数据覆盖和财务时点审计、行业风险审查、原始价格整数手回测与样本外测试，再做至少8–12周前向模拟，覆盖每周信号、报价、手工下单和实际费用核对。是否达标应根据证据决定，不是达到周数自动通过。扩容时重新评估流动性、成本与容量。此版本不应直接作为自动或人工实盘买入建议。

用户风险偏好：以15%最大回撤作为研究筛选和模拟监控的警戒线。`drawdown_alert_breached` 表示研究净值是否越线；不会事后截断损失、保证止损成交或自动停机。若触线，应暂停升级至实盘，检查风险来源及数据/执行差异，不只调参数把历史回撤压低。

因子诊断已实现：每周下一开盘至再下一周开盘的复权收益，计算截面Rank IC、IC正值比例、五分组两端收益及有效样本数。它是未扣费、无成交约束的事后研究，不是实盘组合业绩。完整滚动样本外和成本/持仓数量压力测试仍待真实数据下载后开展。


## BaoStock登录超时排查

如果出现 `timed out / 接收数据异常`，说明请求未完成，不能仅凭这一错误认定缺少权限或数据源永久不可用。

1. 运行 `from ashare.connection import diagnose_baostock; print(diagnose_baostock())`。只能在允许访问服务端TCP端口的环境运行；当前受限云环境不能替代Colab执行此诊断。
2. 返回 `stage=tcp` 且 `ok=False` 表示本次TCP建立失败，原因可能是网络路径、端口过滤或服务端不可达；不应直接下结论为某一原因。
3. TCP通过、`stage=login` 失败表示登录交换没有成功；原始SDK错误码会保留。查询阶段通过且有行情行数才说明此小范围数据访问成功。
4. 子进程超过55秒会终止并返回最后的阶段；即使底层SDK挂起也不会无限卡住Notebook。
5. 下载器登录网络失败最多两次，分别20秒和60秒套接字超时，每次关闭旧连接；非网络错误不自动重试。查询本身不自动重试，已有成功缓存保留。套接字超时不等于整段下载的总耗时上限。
6. 诊断通过后重跑原数据单元。仍失败时保存阶段与错误码，进一步判断网络/服务问题，不反复运行整份回测、不把MODE改回demo冒充修复。

诊断和重试增强只改善定位与连接清理，不保证第三方服务可用。
